# Payloads & Shell Reference
**Maintained by 5kullk3r**

A practical quick-reference repository containing security payloads, shell techniques, exploitation references, and testing methodologies collected and organized for **CTFs, educational research, controlled lab environments, and authorized security assessments**.

The goal of this repository is to keep commonly used security-testing techniques in a simple, searchable, and easy-to-reference format.

---

## Repository Contents

* **[SQL Injection Payloads](./SQLi-Payloads.md)**  
  SQL injection reference covering DBMS identification, authentication bypasses, enumeration, extraction techniques, blind SQLi, and filter-evasion techniques.

* **[CSRF Payloads](./CSRF-Payloads.md)**  
  Cross-Site Request Forgery reference covering GET/POST payloads, auto-submitting forms, file-upload scenarios, JSON requests, and CSRF testing concepts.

* **[SSTI Payloads](./SSTI-Payloads.md)**  
  Server-Side Template Injection payload reference and testing techniques for identifying and assessing template injection vulnerabilities.

* **[XSS Payloads](./XSS-Payloads.md)**  
  Cross-Site Scripting payload reference covering common XSS contexts, payload variations, and testing techniques.

* **[XXE Payloads](./XXE-Payloads.md)**  
  XML External Entity reference covering XXE payload structures, XML parser behavior, and common testing scenarios.
